# Upcoming events

List events in `events.json`. Each needs a `date` (YYYY-MM-DD). An event disappears by itself after its date
(or after `endDate` if given), and the section stays hidden when nothing is upcoming.

    [
      { "title": "State Intellectual Meet", "date": "2026-12-20", "time": "9:30 am", "venue": "Hotel Span, Kozhikode", "note": "Renewal interviews and expert sessions", "link": "https://example.org" }
    ]

`endDate`, `time`, `venue`, `note` and `link` are optional.
