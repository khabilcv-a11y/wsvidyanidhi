# Upcoming events

Easiest way: send the poster and the caption in chat; the details are read from them and added here.

Each event in `events.json` needs a `title` and a `date` (YYYY-MM-DD). It disappears by itself after its date
(or `endDate`). Optional: `time`, `venue`, `note`, `poster` (file in `events/`), `register` (form link), `link` (join link).
